# Start with SoleSense R08

The [project README](README.md) is the team landing page.

1. Review the [current design](revisions/R08/README.md).
2. Download the [R08 build package](revisions/SoleSense_R08_Print_and_Build.zip).
3. Read the [build guide](revisions/R08/docs/BUILD_GUIDE.md) and [shopping list](revisions/R08/docs/SHOPPING_LIST.md).
4. Print the fit coupons and a flexure cassette before the complete enclosure.
5. Follow the [wiring and calibration guide](revisions/R08/docs/WIRING_AND_CALIBRATION.md) for bench work.

Previous R03 package instructions are preserved in [START_HERE_R03.md](START_HERE_R03.md).
