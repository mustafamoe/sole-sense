# Start with SoleSense R07

The [project README](README.md) is the team landing page.

1. Review the [current design](revisions/R07/README.md).
2. Download the [R07 build package](revisions/SoleSense_R07_Print_and_Build.zip).
3. Read the [build guide](revisions/R07/docs/BUILD_GUIDE.md) and [shopping list](revisions/R07/docs/SHOPPING_LIST.md).
4. Print the fit coupons before the complete enclosure.
5. Follow the [wiring and calibration guide](revisions/R07/docs/WIRING_AND_CALIBRATION.md) for bench work.

Previous R03 package instructions are preserved in [START_HERE_R03.md](START_HERE_R03.md).
